## What I Build

**LLM-Powered Analysis Pipelines**
Designed and deployed production LLM pipelines for document understanding and structured data extraction — including prompt engineering, multi-stage reasoning chains, and cost/accuracy optimization.

**Retrieval-Augmented Generation Systems**
Built RAG pipelines using vector embeddings and Azure AI Search to ground LLM responses in large unstructured datasets, improving factual accuracy and reducing hallucination.

**Real-Time Data and Monitoring Platforms**
Engineered live data-quality monitoring systems integrating multiple data sources, automated scoring logic, alerting, and OAuth-based third-party integrations.

**Quantitative Scoring Engines**
Built composite scoring APIs combining multiple technical indicators into production REST endpoints, processing large-scale datasets with consistent reliability.

**Applied AI for Real-World Impact**
Built an AI-driven system to optimize emergency vehicle routing through congested traffic conditions — recognized with 2nd Prize at STEPCON 2025, a national-level technical event.

**Interactive 3D Web Experiences**
Designed and built a 3D interactive developer portfolio using React Three Fiber and Next.js, featuring spatial navigation, guided onboarding, and custom animation systems.
